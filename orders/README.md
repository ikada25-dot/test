# 注文票の書き方

1件の注文ごとに JSON ファイルを1つ作り、`order_video.py` に渡すと約30秒の動画ができます。

```sh
python order_video.py orders/birthday.json --preview --sample  # 1. 確認用の静止画をお客さんに送る
python order_video.py orders/birthday.json --sample            # 2. 透かし入りの動画で最終確認
python order_video.py orders/birthday.json                     # 3. 入金後、透かしなしで納品
python order_video.py orders/birthday.json --vertical          # 縦長版（720×1280）。上の3つにも付けられる
```

`--vertical` を付けると、同じ注文票から縦長（リール・TikTok・ストーリーズ向け）の動画ができます。
ファイル名の最後に `_vertical` が付きます。縦長では、テンプレートの場面を画面の下半分に置き、
上半分に名前と場面の言葉を大きく出します。メッセージは写真の下に入ります。

書き出し先は `out/` です（`--out` で変更可）。4コアのマシンで、30秒の動画が1〜2分で書き出せます。

## 動画の流れ

| 場面 | 長さ | 内容 |
|---|---|---|
| タイトル | 4秒 | `title` と `subtitle` |
| テンプレートの場面 | 12秒 | テンプレートごとの絵と、`scene_captions` の2つの言葉 |
| メッセージ | 行数×1.8秒 + 4秒 | `photo`（あれば）と `messages` |
| おわり | 5秒 | 「`from` より」と `date` |

## 項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `template` | ○ | `birthday`（誕生日）/ `wedding`（結婚）/ `pet`（ペット）/ `shop`（開店・お店のPR） |
| `title` | ○ | 名前など。shop では看板の文字にもなる。10文字くらいまでが見やすい |
| `subtitle` | | タイトルの下の一言 |
| `messages` | ○ | メッセージ。配列で1要素が1段落。自動で折り返す（横長は写真ありで1行14文字・6行まで、なしで22文字・6行まで。縦長は1行14文字で、写真ありは6行、なしは9行まで） |
| `from` | ○ | 送り主。最後に「〜 より」と出る |
| `date` | | 最後に小さく出る日付や住所 |
| `photo` | | 写真のパス（注文票からの相対パス）。色鉛筆風に加工して額に入れる |
| `music` | | BGM のパス。動画の長さで切り、最後の2秒でフェードアウト |
| `scene_captions` | | テンプレートの場面の言葉を2つ（各20文字まで）。省略するとテンプレートの言葉 |
| `hair` | | 女の子の髪: `brown` `black` `blonde` `pink` `gray` か `[R, G, B]` |
| `dress` | | 女の子の服: `red` `blue` `yellow` `green` `pink` `purple` `white` か `[R, G, B]` |
| `accent` | | 下線・ひさし・テーブルクロスなどの色（`dress` と同じ指定） |
| `cat` | | ねこの柄: `chatora`（茶トラ）`kuro`（黒）`shiro`（白）`haiiro`（グレー）`kijitora`（キジトラ） |
| `cat2` | | wedding の2ひき目のねこ |
| `candles` | | birthday のろうそくの数（1〜9） |
| `owner` | | pet で `false` にすると飼い主の女の子を出さない |

## テンプレートの場面

- **birthday**: ケーキのろうそくを吹き消して、紙ふぶき。「ろうそく ふーっ」「おめでとう！」
- **wedding**: 花のアーチの下に、ベールのねこと ちょうネクタイのねこ。「けっこん おめでとう」「すえながく おしあわせに」
- **pet**: 花畑で飼い主がねこをなでる。「いつも そばに いてくれて」「ありがとう」
- **shop**: 女の子がお店にやってきて、OPEN の札がかかる。「あたらしい おみせ」「オープン しました！」

## お客さんに聞くこと（ヒアリングシート）

1. どの用途ですか？（誕生日 / 結婚 / ペット / お店）
2. 主役のお名前と、タイトルの下に入れたい一言
3. メッセージ（全体で100文字くらいまで）
4. 送り主のお名前、入れたい日付
5. 写真を入れますか？（正方形に近い、顔がはっきり写った写真がおすすめ）
6. 女の子の髪・服の色、ねこの柄
7. BGM の希望（お客さんが用意する場合は、著作権に問題のない音源に限る）
8. 納期

## 注意

- 他人の作品のキャラクターや市販の曲は使わないでください（著作権）。BGM はフリー音源か、お客さんが権利を持つ音源にします。
- お客さんの写真は納品後に削除し、ポートフォリオに使うときは許可を取ります。
